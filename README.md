# E-Commerce Sales Analysis Dashboard | Power BI

## 📊 Project Overview

An interactive E-commerce Sales Analysis Dashboard built using Microsoft Power BI to analyze sales performance, customer orders, cancellations, products, categories, and regional revenue trends.

## 🎯 Business Problem

E-commerce businesses need a clear view of their sales performance to understand:

* Which products generate the highest revenue?
* Which categories perform best?
* Which states contribute the most revenue?
* How are revenue and orders performing over time?
* What is the impact of cancelled orders on revenue?

## 🔍 Analysis Performed

The dashboard provides insights into:

* Total Revenue
* Average Order Value (AOV)
* Lost Revenue due to Cancellation
* Cancellation Rate
* Total Orders
* Revenue by Product
* Revenue by Category
* Revenue by State
* Revenue Trend by Year and Quarter
* Category-wise filtering
* Date-wise filtering

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization
* Data Cleaning & Transformation

## 📈 Dashboard Features

* Interactive category slicer
* Date range filter
* KPI cards
* Product-wise revenue analysis
* Category-wise revenue analysis
* State-wise revenue analysis
* Revenue trend analysis
* Interactive and dynamic visuals

## 💡 Key Insights

The dashboard makes it easier to identify high-performing products and categories, compare regional revenue, monitor cancellation-related revenue loss, and understand sales trends over time.
